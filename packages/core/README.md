# @crewmind/core

> **Pre-alpha, under active development.**

Shared building blocks for [Crewmind](https://www.npmjs.com/package/crewmind), the encrypted team memory for AI coding assistants: record schemas (Zod), canonical JSON for signing, and time-sortable IDs. Crypto, ranking and the privacy scanner will be added later.

The API is unstable until 1.0. Requires Node.js ≥ 22.13.
